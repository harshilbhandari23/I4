# I⁴ — International Institute of Innovation & Intelligence

Static marketing site for I⁴ (I Power 4). Single self-contained page (`index.html`), no build step or framework — fonts load from Google Fonts, everything else is local under `assets/`.

## Local preview

Just open `index.html` in a browser, or serve the folder with any static file server, e.g.:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deployment

This repo is deployed via **GitHub Pages** from the `main` branch root.
